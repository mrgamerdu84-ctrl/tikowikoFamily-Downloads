# Statuts / couleurs du catalogue tikowikoFamily
#
# Le créateur peut choisir manuellement la couleur depuis :
# GitHub > Actions > "Changer le statut d'une application" > Run workflow
#
# Il choisit d'abord l'application, puis le statut :
#
# 🩵 Bleu clair = Importé depuis Lovable / à vérifier
#                  -> des traces Lovable sont présentes dans le dépôt.
#                  -> autonomie à vérifier avant publication publique.
#                  -> APK publiques masquées pendant la vérification.
#
# 🟣 Violet = En réflexion / projet en suspens
#             -> on réfléchit à la suite : continuer, revoir ou arrêter le projet.
#             -> APK publiques masquées.
#
# 🟡 Jaune  = Test développeur
#             -> le développeur teste actuellement l'APK.
#             -> APK publiques masquées, brouillons accessibles au créateur.
#
# 🟠 Orange = Correction active
#             -> bugs ou correctifs en cours.
#             -> APK publiques masquées.
#
# 🔵 Bleu   = Développement actif
#             -> projet actuellement développé.
#
# 🟢 Vert   = Disponible / test
#             -> APK de test disponible au public ou application sur Google Play Test.
#
# ⚪ Gris   = Stable pour le moment
#             -> APK disponible, développement calme/stable.
#
# 🔴 Rouge  = Indisponible
#             -> l'APK ne doit pas être proposée au public.
#
# ⚙️ Auto   = Retire le choix manuel et rend la main au calcul automatique.
#
# Les statuts 🩵 🟣 🟡 🟠 🔴 bloquent le téléchargement public.
# Les statuts 🔵 🟢 ⚪ permettent une APK publique si une Release existe.
