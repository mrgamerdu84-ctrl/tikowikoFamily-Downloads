# Statuts de couleurs automatiques
#
# Ce fichier n'est plus utilisé pour choisir les couleurs manuellement.
# Le catalogue calcule maintenant la couleur automatiquement :
#
# 🟠 Orange = correction de bugs / correctifs détectés
# 🔵 Bleu   = développement actif avec APK récente
# ⚪ Gris   = APK disponible, pas de correction récente détectée
# 🔴 Rouge  = aucune APK publique disponible
#
# La raison exacte est affichée dans la colonne "Pourquoi cette couleur ?"
# du catalogue README.
